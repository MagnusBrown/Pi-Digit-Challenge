# Pi Digit Challenge – Ultimate Local Edition

Netlify-klar versjon uten database.

## Funksjoner
- Konkurransemodus: 20, 50, 100, 200, 400, 750 og 1 000 desimaler
- Treningsmodus uten liv eller medaljer
- Tiergruppehjelp i tre sekunder ved feil
- Manuell knapp for å vise tiergruppen
- 33 achievements med AI-lagde badges
- Klikkbare badges med beskrivelse og opplåsingsdato
- Full profilside med rekorder per modus
- Klikkbar løpshistorikk og detaljert statistikk
- Eksport, import og sletting av lokale data
- Alt lagres lokalt i nettleseren

## Netlify
Dra hele den utpakkede prosjektmappen inn i Netlify. `index.html` må ligge direkte i roten.


## Nivå og XP
- Nivåsystem fra 1 til 100
- Alle fullførte løp gir XP
- Dypere progresjon i π gir stadig mer XP
- Konkurranse gir mer XP enn trening
- Nøyaktighet, fullføring og medaljer påvirker XP
- XP-kravet øker kraftig mot nivå 100
- Egne achievements ved nivå 5, 10, 25, 50 og 100
